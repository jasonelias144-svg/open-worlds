A. FIRST, IN PROSE: HOW A MEMBER'S RECORDS STAY CHAINED

Before the first file, answer this in a few paragraphs. Do not build
your answer in this step: the founder and I read it first, as you
proposed for the rest.

A member who has joined a room but does not keep it writes records
ahead: each names, as its previous, the record the member wrote
before it. The keeper takes them in a batch. When the keeper refuses
one, a refusal takes its place in the log, and the next record in the
batch names, as its previous, a record that is not there. Your test
refusal_consumes_seq_keeping_batch_aligned shows it.

What should happen? Some ways it could go, for you to weigh, or to
put aside for a better one:

  - the keeper stops at the first refusal and gives back the rest,
    and the member writes them again on the log as it now stands;
  - the refusal carries the hash of the record it refused, and the
    check lets the next record name that hash;
  - the member's records name the room's log, not each other, and
    the keeper sets each one's place when it takes it.

Say which you would choose and why, what it costs, and what the check
of a room's log must then hold. Say too how it fares when two members
send batches at the same time.

B. TWO REPAIRS, IN CODE

  1. invalid_log_refused_at_attach. As far as we can see, the log
     this test builds is honest. Room::create writes one record,
     room_created. In a room that signs heads, no head is due until a
     record is added after it, so that log has no heads, and clearing
     them changes nothing. Attaching to it rightly succeeds. Make the
     test forge something the check of a log refuses, so that it
     tests what its name says.

  2. port_landing_refused_in_chat_room. accept_one asks for the
     record's author before it looks at what kind of record it is. A
     port landing names no author, so accept_pending stops the whole
     batch with "accept_pending: no author", and never reaches your

     such a record on the record, as the test expects, and say whose
     id the refusal carries when the record names no author.

  Both were tried here, in a throwaway copy: with the test forging

pub(crate) fn sign_record<T, F>(
    mut rec: T,
    signer: &Keypair,
    wrap: fn(T) -> record::Record,
    set_proof: F,
) -> Result<T>
where
    T: serde::Serialize + Clone,
    F: FnOnce(&mut T, ProofOrArray),
{
    let body = hash::body_for_signing(&wrap(rec.clone()))?;
    let sig = signer.sign(&body);
    let proof = ProofOrArray::Single(Proof::create(signer, &sig));
    set_proof(&mut rec, proof);
    Ok(rec)
}

pub(crate) fn sign_record_dual<T, F>(
    mut rec: T,
    subject: &Keypair,
    room: &Keypair,
    wrap: fn(T) -> record::Record,
    set_proof: F,
) -> Result<T>
where
    T: serde::Serialize + Clone,
    F: FnOnce(&mut T, ProofOrArray),
{
    let body = hash::body_for_signing(&wrap(rec.clone()))?;
    let subj_sig = subject.sign(&body);
    let room_sig = room.sign(&body);
    let subj_proof = Proof::create(subject, &subj_sig);
    let room_proof = Proof::create(room, &room_sig);
    set_proof(&mut rec, ProofOrArray::array(vec![subj_proof, room_proof]));
    Ok(rec)
}

pub(crate) fn sign_record_triple<T, F>(
    mut rec: T,
    a: &Keypair,
    b: &Keypair,
    room: &Keypair,
    wrap: fn(T) -> record::Record,
    set_proof: F,
) -> Result<T>
where
    T: serde::Serialize + Clone,
    F: FnOnce(&mut T, ProofOrArray),
{
    let body = hash::body_for_signing(&wrap(rec.clone()))?;
    let a_sig = a.sign(&body);
    let b_sig = b.sign(&body);
    let room_sig = room.sign(&body);
    set_proof(&mut rec, ProofOrArray::array(vec![
        Proof::create(a, &a_sig),
        Proof::create(b, &b_sig),
        Proof::create(room, &room_sig),
    ]));
    Ok(rec)
}

//! hold the key of.
//!
//! The participant has the room's published `RoomLog`, their own
//! `Keypair`, and a `pending` list of author-signed records they
//! intend to submit. Head-mode rooms accept author-signed records
//! past the last head; the keeper appends them (see
//! `Room::accept_pending`) and the next head covers them. In
//! per-record mode, only the keeper can post, because every
//! record needs the room's countersignature and that changes its
//! hash.

    pending: Vec<Record>,

    /// accepting it — an invalid log is not a room to join.
    pub fn from_log(log: RoomLog, user_kp: Keypair) -> Result<Self> {
        verify_log(&log)?;
        Ok(JoinedRoom { log, user_kp, pending: Vec::new() })

    pub fn pending(&self) -> &[Record] { &self.pending }

        out
    }

    }

        (self.log.records.len() + self.pending.len()) as u64
    }

            r.hash().ok()
        } else {
            self.log.records.last().and_then(|r| r.hash().ok())

    fn replay_membership(&self) -> (bool, Option<String>) {
        let user_id = self.user_kp.did();
        let mut is_member = false;
        let mut tier: Option<String> = None;
        for rec in self.log.records.iter().chain(self.pending.iter()) {

                    is_member = false;
                    tier = None;
                }
                _ => {}
            }
        }
        (is_member, tier)
    }

        self.replay_membership().0
    }

        self.head_mode_ok()?;

            return Err(Error::Policy("joined_room: already a member".into()));
        }
        if tier_rank(tier).is_none() {
            return Err(Error::Policy(format!("unknown tier: {tier}")));

    /// not check policy — that's the keeper's job. This catches
    /// local formatting errors before sending.
    pub fn verify_pending(&self) -> Result<()> {
        let mut running_seq = self.log.records.len() as u64;
        let mut running_prev = self.log.records.last().and_then(|r| r.hash().ok());
        for (i, rec) in self.pending.iter().enumerate() {
            if rec.seq() != running_seq {
                return Err(Error::Chain(format!(
                    "pending {i}: seq {} != expected {}",
                    rec.seq(), running_seq
                )));
            }
            if rec.prev() != running_prev.as_ref() {
                return Err(Error::Chain(format!("pending {i}: prev mismatch")));
            }
            let Some(author) = rec.author_id() else {
                return Err(Error::Policy(format!("pending {i}: no author")));
            };
            let body = crate::hash::body_for_signing(rec)?;
            let proof = rec.proof().find_by_method(author)
                .ok_or_else(|| Error::Verification(format!(
                    "pending {i}: missing author proof"
                )))?;
            proof.verify(&body)?;
            running_seq += 1;
            running_prev = Some(rec.hash()?);
        }
        Ok(())
    }

        if tier_rank(&m.tier).unwrap_or(0) < tier_rank("communicate").unwrap() {
            return self.refuse(author, "".into(), "insufficient_tier");
        }
        if text.len() as u64 > self.template.max_msg_len {
            return self.refuse(author, "".into(), "message_too_long");
        }
        if !self.rate_ok(&author) {
            return self.refuse(author, "".into(), "rate_limit");
        }
        if !self.inter_ai_pace_ok(m.is_ai) {
            return self.refuse(author, "".into(), "inter_ai_pace");
        }
        let rec = Message::new(
            self.world_id.clone(), self.next_seq(), self.last_hash(),
            author.clone(), text.into(), kind.into(),
        );
        let signed = if self.template.head_interval <= 1 {
            crate::sign_record_dual(rec, author_kp, &self.keypair, Record::Message, |r, p| r.proof = p)?
        } else {
            crate::sign_record(rec, author_kp, Record::Message, |r, p| r.proof = p)?
        };
        let out = Record::Message(signed);
        self.push(out.clone())?;
        Ok(out)
    }

    pub fn redact(
        &mut self,
        subject_kp: &Keypair,
        target_hash: &str,
        rule: &str,
        reason: &str,
    ) -> Result<Record> {
        let subject = subject_kp.did();
        let Some(m) = self.members.get(&subject).cloned() else {
            return self.refuse(subject, "".into(), "not_a_member");
        };
        let target = self.records.iter()
            .find(|r| r.hash().ok().as_deref() == Some(target_hash));
        let target_msg = match target {
            Some(Record::Message(msg)) => msg,
            _ => return self.refuse(subject, "".into(), "target_not_found"),
        };
        if self.template.moderation == "none" {
            return self.refuse(subject, "".into(), "moderation_disabled");
        }
        let is_author = target_msg.author_id == subject;
        let is_mod = self.template.moderation == "moderator"
            && tier_rank(&m.tier).unwrap_or(0) >= tier_rank("control").unwrap();
        let actor_role = if is_author {
            "author"
        } else if is_mod {
            "moderator"
        } else {
            return self.refuse(subject, "".into(), "not_allowed");
        };
        if !self.template.redaction_rules.iter().any(|r| r == rule) {
            return self.refuse(subject, "".into(), "rule_not_allowed");
        }
        let rec = Redact::new(
            self.world_id.clone(), self.next_seq(), self.last_hash(),
            subject.clone(), target_hash.into(),
            actor_role.into(), rule.into(), reason.into(),
        );
        let signed = if self.template.head_interval <= 1 {
            crate::sign_record_dual(rec, subject_kp, &self.keypair, Record::Redact, |r, p| r.proof = p)?
        } else {
            crate::sign_record(rec, subject_kp, Record::Redact, |r, p| r.proof = p)?
        };
        let out = Record::Redact(signed);
        self.push(out.clone())?;
        Ok(out)
    }

    pub fn override_ai(&mut self, overrider_kp: &Keypair, overrides_hash: &str, reason: &str) -> Result<Record> {
        let overrider = overrider_kp.did();
        let Some(m) = self.members.get(&overrider).cloned() else {
            return Err(Error::Policy("overrider is not a member".into()));
        };
        if m.is_ai {
            return Err(Error::Policy("only humans can override".into()));
        }
        if tier_rank(&m.tier).unwrap_or(0) < tier_rank("control").unwrap() {
            return Err(Error::Policy("insufficient tier".into()));
        }
        let target = self.records.iter()
            .find(|r| r.hash().ok().as_deref() == Some(overrides_hash));
        let Some(target_rec) = target else {
            return Err(Error::Policy("target not found".into()));
        };
        let Some(author) = target_rec.author_id() else {
            return Err(Error::Policy("target has no author".into()));
        };
        let is_ai = self.members.get(author).map(|m| m.is_ai).unwrap_or(false);
        if !is_ai {
            return Err(Error::Policy("can only override AI records".into()));
        }
        if let Some(spec) = &self.template.moderator {
            if &spec.moderator_id == author && !spec.can_be_overridden {
                return Err(Error::Policy("this AI cannot be overridden".into()));
            }
        }
        let rec = HumanOverride::new(
            self.world_id.clone(), self.next_seq(), self.last_hash(),
            overrides_hash.into(), overrider.clone(), "none".into(), reason.into(),
        );
        let signed = if self.template.head_interval <= 1 {
            crate::sign_record_dual(rec, overrider_kp, &self.keypair, Record::HumanOverride, |r, p| r.proof = p)?
        } else {
            crate::sign_record(rec, overrider_kp, Record::HumanOverride, |r, p| r.proof = p)?
        };
        let out = Record::HumanOverride(signed);
        self.push(out.clone())?;
        Ok(out)
    }

    pub fn restore_incident(&mut self, restorer_kp: &Keypair, redact_hash: &str, reason: &str) -> Result<Record> {
        let restorer = restorer_kp.did();
        let Some(m) = self.members.get(&restorer).cloned() else {
            return Err(Error::Policy("restorer is not a member".into()));
        };
        if m.is_ai {
            return Err(Error::Policy("only humans can restore".into()));
        }
        if tier_rank(&m.tier).unwrap_or(0) < tier_rank("control").unwrap() {
            return Err(Error::Policy("insufficient tier".into()));
        }
        let target = self.records.iter()
            .find(|r| r.hash().ok().as_deref() == Some(redact_hash));
        match target {
            Some(Record::Redact(_)) => {}
            _ => return Err(Error::Policy("restore target must be a redact record".into())),
        }
        let rec = HumanOverride::new(
            self.world_id.clone(), self.next_seq(), self.last_hash(),
            redact_hash.into(), restorer.clone(), "restore".into(), reason.into(),
        );
        let signed = if self.template.head_interval <= 1 {
            crate::sign_record_dual(rec, restorer_kp, &self.keypair, Record::HumanOverride, |r, p| r.proof = p)?
        } else {
            crate::sign_record(rec, restorer_kp, Record::HumanOverride, |r, p| r.proof = p)?
        };
        let out = Record::HumanOverride(signed);
        self.push(out.clone())?;

    }

    pub fn declare_succession(
        &mut self,
        outgoing_kp: &Keypair,
        incoming_kp: &Keypair,
        shard_hash: &str,
        reason: &str,
    ) -> Result<Record> {
        let outgoing_id = outgoing_kp.did();
        let incoming_id = incoming_kp.did();
        let Some(m) = self.members.get(&outgoing_id) else {
            return Err(Error::Policy("outgoing is not a member".into()));
        };
        if tier_rank(&m.tier).unwrap_or(0) < tier_rank("control").unwrap() {
            return Err(Error::Policy("outgoing must be control or higher".into()));
        }
        if outgoing_id == incoming_id {
            return Err(Error::Policy("outgoing and incoming must differ".into()));
        }
        let rec = ModeratorSuccession::new(
            self.world_id.clone(), self.next_seq(), self.last_hash(),
            outgoing_id, incoming_id, shard_hash.into(), reason.into(),
        );
        let signed = crate::sign_record_triple(
            rec, outgoing_kp, incoming_kp, &self.keypair,
            Record::ModeratorSuccession, |r, p| r.proof = p,
        )?;
        let out = Record::ModeratorSuccession(signed);
        self.push(out.clone())?;
        Ok(out)
    }

    /// Accept pending records from a participant. Each is validated
    /// against the room's law; accepted records are appended, and
    /// rejected records produce a `Refusal` record at that seq (so
    /// the chain advances by exactly one per pending record, and the
    /// participant's subsequent pending seqs still line up).
    ///
    /// Head-mode only. In per-record mode the room must countersign
    /// each record, which changes its hash — `accept_pending` refuses
    /// to run there.
    ///
    /// The rules checked here mirror `verify_log`'s per-record rules:
    /// a record that this accepts should produce a log that passes
    /// `verify_log`. If a record this accepts would still fail
    /// `verify_log`, that is a bug — call verify_log on the result
    /// after every batch as the keeper's final defence.
    pub fn accept_pending(&mut self, pending: &[Record]) -> Result<Vec<CommitOutcome>> {
        if self.template.head_interval <= 1 {
            return Err(Error::Policy(
                "accept_pending: per-record mode rooms must use Room::post".into(),
            ));
        }
        let mut outcomes = Vec::new();
        for rec in pending {
            let outcome = self.accept_one(rec)?;
            outcomes.push(outcome);
        }
        Ok(outcomes)
    }

    fn accept_one(&mut self, rec: &Record) -> Result<CommitOutcome> {
        let request_hash = rec.hash()?;

        let needs_room_proof = matches!(
            rec,
            Record::RoomCreated(_)
                | Record::Refusal(_)
                | Record::KnowledgeShardExport(_)
                | Record::ModeratorSuccession(_)
                | Record::ModeratorScope(_)
        );
        if needs_room_proof {
            let author = rec.author_id().cloned().unwrap_or_else(|| self.world_id.clone());
            return self.refuse_outcome(author, request_hash, "record_type_requires_room_proof");
        }

        let expected_seq = self.records.len() as u64;
        if rec.seq() != expected_seq {
            return Err(Error::Policy(format!(
                "accept_pending: seq mismatch (expected {expected_seq}, got {})",
                rec.seq()
            )));
        }
        let expected_prev = self.records.last().and_then(|r| r.hash().ok());
        if rec.prev() != expected_prev.as_ref() {
            return Err(Error::Policy("accept_pending: prev mismatch".into()));
        }

        let Some(author) = rec.author_id().cloned() else {
            return Err(Error::Policy("accept_pending: no author".into()));
        };
        let body = crate::hash::body_for_signing(rec)?;
        let proof = rec.proof().find_by_method(&author)
            .ok_or_else(|| Error::Policy("accept_pending: no author proof".into()))?;
        proof.verify(&body)?;

        if let Record::Join(j) = rec {
            if self.members.contains_key(&author) {
                return self.refuse_outcome(author, request_hash, "already_member");
            }
            if tier_rank(&j.tier).is_none() {
                return self.refuse_outcome(author, request_hash, "unknown_tier");
            }
            if self.template.personal {
                return self.refuse_outcome(author, request_hash, "personal_room");
            }
            if self.template.membership == "human_only" && j.is_ai {
                return self.refuse_outcome(author, request_hash, "human_only_room");
            }
            if self.template.membership == "ai_only" && !j.is_ai {
                return self.refuse_outcome(author, request_hash, "ai_only_room");
            }
            if self.template.join_policy == "invite" {
                return self.refuse_outcome(author, request_hash, "invite_required");
            }
            if self.template.join_policy == "approval" {
                return self.refuse_outcome(author, request_hash, "approval_required");
            }
            self.members.insert(author, Member { tier: j.tier.clone(), is_ai: j.is_ai });
            self.push(rec.clone())?;
            return Ok(accept_outcome(request_hash));
        }

        let Some(m) = self.members.get(&author).cloned() else {
            return self.refuse_outcome(author, request_hash, "not_a_member");
        };

        if let Record::Leave(l) = rec {
            self.members.remove(&l.subject_id);
            self.push(rec.clone())?;
            return Ok(accept_outcome(request_hash));
        }

        if let Record::Message(msg) = rec {
            if tier_rank(&m.tier).unwrap_or(0) < tier_rank("communicate").unwrap() {
                return self.refuse_outcome(author, request_hash, "insufficient_tier");
            }
            if msg.text.len() as u64 > self.template.max_msg_len {
                return self.refuse_outcome(author, request_hash, "message_too_long");
            }
            if !self.rate_ok(&author) {
                return self.refuse_outcome(author, request_hash, "rate_limit");
            }
            if !self.inter_ai_pace_ok(m.is_ai) {
                return self.refuse_outcome(author, request_hash, "inter_ai_pace");
            }
            self.push(rec.clone())?;
            return Ok(accept_outcome(request_hash));
        }

        if let Record::Redact(r) = rec {
            if self.template.moderation == "none" {
                return self.refuse_outcome(author, request_hash, "moderation_disabled");
            }
            let target = self.records.iter()
                .find(|x| x.hash().ok().as_deref() == Some(&r.target_hash));
            let target_msg = match target {
                Some(Record::Message(msg)) => msg,
                _ => return self.refuse_outcome(author, request_hash, "target_not_found"),
            };
            let is_author = target_msg.author_id == r.subject_id;
            let is_mod = self.template.moderation == "moderator"
                && tier_rank(&m.tier).unwrap_or(0) >= tier_rank("control").unwrap();
            let role_ok = match r.actor_role.as_str() {
                "author" => is_author,
                "moderator" => is_mod,
                _ => false,
            };
            if !role_ok {
                return self.refuse_outcome(author, request_hash, "not_allowed");
            }
            if !self.template.redaction_rules.iter().any(|x| x == &r.rule) {
                return self.refuse_outcome(author, request_hash, "rule_not_allowed");
            }
            self.push(rec.clone())?;
            return Ok(accept_outcome(request_hash));
        }

        if let Record::HumanOverride(o) = rec {
            if m.is_ai {
                return self.refuse_outcome(author, request_hash, "only_humans_can_override");
            }
            if tier_rank(&m.tier).unwrap_or(0) < tier_rank("control").unwrap() {
                return self.refuse_outcome(author, request_hash, "insufficient_tier");
            }
            let target = self.records.iter()
                .find(|x| x.hash().ok().as_deref() == Some(&o.overrides_hash));
            let Some(target_rec) = target else {
                return self.refuse_outcome(author, request_hash, "target_not_found");
            };
            match o.action.as_str() {
                "none" => {
                    let Some(target_author) = target_rec.author_id() else {
                        return self.refuse_outcome(author, request_hash, "override_target_has_no_author");
                    };
                    let target_is_ai = self.members.get(target_author).map(|x| x.is_ai).unwrap_or(false);
                    if !target_is_ai {
                        return self.refuse_outcome(author, request_hash, "override_target_must_be_ai");
                    }
                }
                "restore" => {
                    if !matches!(target_rec, Record::Redact(_)) {
                        return self.refuse_outcome(author, request_hash, "restore_target_must_be_redact");
                    }
                }
                _ => {
                    return self.refuse_outcome(author, request_hash, "unknown_override_action");
                }
            }
            self.push(rec.clone())?;
            return Ok(accept_outcome(request_hash));
        }

        if matches!(rec, Record::PortLanding(_) | Record::Bookmark(_) | Record::Presence(_)) {
            return self.refuse_outcome(author, request_hash, "not_valid_in_chat_room");
        }

        Err(Error::Policy("accept_pending: unknown record type".into()))
    }

    fn refuse_outcome(
        &mut self,
        author: DidKey,
        request_hash: String,
        reason: &str,
    ) -> Result<CommitOutcome> {
        let r = self.refuse(author, request_hash.clone(), reason)?;
        Ok(CommitOutcome {
            request_hash,
            accepted: false,
            refusal_hash: Some(r.hash()?),
            reason: Some(reason.into()),
        })
    }

    pub fn visible_log(&self) -> Vec<serde_json::Value> {
        visible_log_from(&self.records)
    }
}

fn accept_outcome(request_hash: String) -> CommitOutcome {
    CommitOutcome {
        request_hash,
        accepted: true,
        refusal_hash: None,
        reason: None,
    }
}

#[test]
fn head_mode_author_redacts_own_message() -> Result<()> {
    let mut alice_room = make_head_mode_room(3);
    let bob = Keypair::generate();
    let msg_hash = {
        let mut joined = JoinedRoom::from_log(alice_room.log(), bob.clone())?;
        joined.request_join("communicate", false)?;
        let msg = joined.post("oops", "normal")?;
        let h = msg.hash()?;
        alice_room.accept_pending(&joined.export_pending())?;
        h
    };

    // Bob redacts his own message via pending.
    {
        let mut joined = JoinedRoom::from_log(alice_room.log(), bob.clone())?;
        // Local JoinedRoom has no redact method; forge it with the
        // right shape (author role on own message) and submit.
        let log = joined.log();
        let prev = log.records.last().unwrap().hash()?;
        let mut red = Redact::new(
            log.world_id.clone(),
            log.records.len() as u64,
            Some(prev),
            bob.did(),
            msg_hash,
            "author".into(),
            "author_request".into(),
            "my bad".into(),
        );
        let wrapped = Record::Redact(red.clone());
        red.proof = sign_single(&wrapped, &bob);
        let outcomes = alice_room.accept_pending(&[Record::Redact(red)])?;
        assert_eq!(outcomes.len(), 1);
        assert!(outcomes[0].accepted);
    }

    verify_log(&alice_room.log())?;
    Ok(())
}
