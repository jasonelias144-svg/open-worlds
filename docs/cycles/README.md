# Cycles

One record per cycle. Each cycle changes the conditions and starts again.

| Cycle | Question | Record |
| --- | --- | --- |
| 0 | Do walkers in a crowded corridor form lanes, and a keep-right convention? | [cycle-000.md](cycle-000.md) |

## A record holds

- **Question:** what this cycle asks.
- **Conditions:** the world, the agents, what changed from the last cycle.
- **What happened:** results, each with the command and seeds that produced
  it. Numbers come only from real runs, saved next to the record.
- **Conventions:** rules that formed that nobody wrote.
- **Exits:** who left, when, and where to.
- **What this suggests for the next cycle.**
